Step 03 · 底层机制

看懂这几个词，构筑就不会走偏

背包乱斗的流派强弱几乎都围绕下面这套资源循环展开，看到商店里加这些数值的装备，优先考虑。

🪙

金币与商店刷新

每回合金币有限，装备靠随机刷新出现。越早决定流派，越能把有限的金币花在同一条核心线上，而不是东买一件西买一件。

⚡

触发 / 冷却（星星物品）

带「星星」标记的物品按冷却自动触发，是绝大多数流派的主引擎。加触发速度、推进冷却的装备价值极高。

🔥

增益与减益堆叠

狂热、充能、恢复、尖刺、幸运属于增益；中毒、冰冷、致盲属于减益。多数流派靠堆层数滚雪球，层数越高收益越大。

🧩

合成与背包格

两件低阶装备可在商店合成高阶件，但会占用背包格子。合成路线清晰的流派（如游侠弓系）更容易成型。

🎖️

子职业分支

每个职业有多个子职业，用对应「子职业物品」解锁，等于官方预设的流派方向。本工具把子职业也当作一种流派收录。

🧭

怎么用这个工具

早期装备少时，匹配度普遍偏低是正常的 —— 看「还缺哪些核心件」那一栏，那就是你下一轮商店的购物清单。

  • 当前 116 个去重核心件中 76 个已收录配方（65.5%），其余 40 个按「商店直购件」处理； 两类物品的初始包/子职业物品（如棋子、拼图背包、龙蛋、幽灵伙伴）需要角色解锁或进化，未计入配方
  • 进度条口径：流派卡上的百分比是路线进度（含基础件） = 已持有 ∪ 材料齐全可合成 ∪ 手动标记 的「升级路线」件数 ÷ 路线总件数， 所以前期只买到基础材料时进度条也会动；旁边小字「核心件命中」才是决定排序与「推荐」标的评分口径
  • 按回合分阶段的商店推荐：新增「当前回合」选择器（前期 1-3 / 中期 4-6 / 后期 7+）， 按物品稀有度 tier 过滤推荐清单，并在每个流派卡内展开「🗺️ 升级路线」； 回合门槛（PHASES 的 maxTier）是按经济节奏估算的近似值，不代表游戏内的硬性刷新规则
  • 流派卡排序规则：流派卡会按「核心件命中」从高到低实时重排（不是只换「推荐」标）， 每次勾选装备 / 文本框输入 / 切换回合阶段 / 点推荐行「标记已持有」都会立即重算位置； 同分时先看路线进度（含基础件）谁更接近成型，仍相同则保持职业内原始顺序（稳定排序）； 卡片左上角的 #1 #2 #3 就是当前名次，鼠标悬停结果区右上角「排序：核心件命中 ↓」可看完整规则
更新数据的方法
  • 打开本文件，找到脚本顶部注释的 GAME_META（改版本号 / 数据日期）
  • 再找 BUILDS 常量：每个职业是一组 {id,name,builds:[...]}
  • 每个流派含 name / desc / core[] / synth / synergy，照着已有格式加一行即可
  • 合成配方单独放在 RECIPES 常量里：{ "成品名": [{n:"材料名",c:数量,r:"稀有度"}] }， 启动时会自动注入到每个核心件的 recipe 字段；同名材料写在同一项里加数量即可（如短弓×2）
  • 评分口径：命中核心件数 ÷ 核心件总数，其中「命中」= 直接持有 ∪ 材料齐全可合成 ∪ 手动标记已合成； 进度条另算「路线进度」= 路线内命中件数 ÷ 路线总件数
  • 通用物品放在 COMMON_GROUPS 常量里（[{id,title,items:[{n,r}]}]）， 改分组标题或增删条目即可；COMMON_POOL 是拍平后的兼容数组
  • 稀有度体系：RARITY_TIER 把 普通→罕见→史诗→传说→神级→特别 映射为 tier 0→5； 稀有度查找优先级 = 核心件 it.r → RECIPES 材料的 r → 通用物品表 → MID_RARITY 兜底
  • 阶段门槛：PHASES 里每段一个 maxTier（前期 1 / 中期 2 / 后期 5）， 改这里即可调整「几回合该买多贵的东西」
